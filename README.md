# REST API Testing with Katalon Studio

This repository includes automated **REST API test cases** built using **Katalon Studio**.  
The tests validate multiple HTTP methods and ensure that API endpoints work correctly and reliably.  

## 📝 Features Tested
The test cases cover the following HTTP methods:
- **GET** – Retrieve data from API  
- **POST** – Create new records  
- **PUT** – Update existing records  
- **DELETE** – Remove records  

Each test case validates:  
- Response status codes  
- Response body and data integrity  
- Headers (if required)  
- Use of **variables and parameters** for flexibility and reusability  

## 🛠️ Tools & Technologies
- [Katalon Studio](https://katalon.com/)  
- Built-in Katalon API testing features  
- Groovy scripting (for assertions and logic)
